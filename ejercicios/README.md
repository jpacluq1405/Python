# 🧩 Ejercicios de Python

Esta carpeta contiene ejercicios ordenados de menor a mayor dificultad. Intenta resolverlos antes de consultar ejemplos y modifica los programas para experimentar.

## 🟢 Nivel 1 — Fundamentos
1. **Hola, usuario** — pide el nombre y saluda.
2. **Datos personales** — practica variables y tipos de datos.
3. **Calculadora básica** — suma, resta, multiplica y divide dos números.
4. **¿Par o impar?** — usa el operador módulo.
5. **El mayor de tres** — compara tres números.

## 🟡 Nivel 2 — Condiciones y bucles
6. **Tabla de multiplicar** — muestra la tabla del 1 al 10.
7. **Contador** — cuenta desde 1 hasta un número.
8. **Adivina el número** — juega con un número aleatorio y recibe pistas.

## 🟠 Nivel 3 — Listas y funciones
9. **Estadísticas de una lista** — calcula cantidad, suma, media, mínimo y máximo.
10. **Número primo** — usa una función para comprobar si un número es primo.

## 🔴 Nivel 4 — Mini retos
11. **Contador de palabras** — cuenta palabras y caracteres de una frase.
12. **Gestor de tareas** — añade, muestra y completa tareas desde un menú.

## ▶️ Cómo ejecutar un ejercicio
Desde la carpeta principal del repositorio:

```bash
python ejercicios/01_hola_usuario.py
```

En algunos sistemas tendrás que usar `python3` en lugar de `python`.

¡Avanza a tu ritmo e intenta entender cada línea antes de pasar al siguiente reto!
