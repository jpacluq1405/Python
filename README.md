## 🚀 Primeros pasos

Necesitas tener instalado [Python](https://www.python.org/downloads/).

Ejecuta un archivo desde la terminal con:

```bash
python hola_mundo.py
```

En algunos sistemas puedes necesitar usar `python3 hola_mundo.py`.
