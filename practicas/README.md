# 🧪 Prácticas de Python

Aquí organizaré prácticas de clase, actividades guiadas y ejemplos que haga mientras estudio programación.

Para cada práctica, intenta incluir:

- **Objetivo:** qué se aprende.
- **Código:** la solución en Python.
- **Pruebas:** ejemplos de ejecución.
- **Notas:** dudas o conceptos nuevos.
